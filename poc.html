Tool for converting re3data v4 metadata to JSON-LD

Repository managers must
a) find the re3 identifier for their own repository, like re3data example file: r3d100000001 and
b) use their browser to visit the API address adding only the number of the record, like: https://www.re3data.org/api/v40/repository/100000001. STEP 1) Copy the XML source from the browser (right-click and view source before copying the full XML) and paste it below, or choose a saved JSON-LD/last session to continue. STEP 2) Parse XML into the editor and edit or supplement fields. STEP 3) Copy and verify the generated JSON-LD.

1. Paste raw re3data v4 XML
2. Edit harvested metadata & supplement

Core identity & dates

Subjects, keywords & formats

Providers, institutions & funders

Access, licenses & policies

Contacts, APIs, software & standards

Quality, relations & additional context

3. Generated HTML-embedded JSON-LD
